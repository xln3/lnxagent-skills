# 调用模板

## 1. 默认改写

```text
用无敌人话修改处理下面这段。标准改写，保持事实、立场和术语，只给正文：

【原文】
```

## 2. 轻改

```text
用无敌人话修改轻改。保留原结构和我的语气，只去掉模板感、重复和无用修饰，不扩写，只给正文：

【原文】
```

## 3. 重构重写

```text
用无敌人话修改重构这段。可以推翻原句和段落顺序，但不得改变事实、数字、责任和结论强度。先把核心判断前置，再按读者最需要的信息重写。只给正文：

【原文】
```

## 4. 诊断 AI 腔

```text
用无敌人话修改的九类体系分析下面文本。不要笼统说“像 AI”，请引用具体句子，指出最严重的 3—7 个问题、为什么有问题以及修改优先级。先不要重写：

【原文】
```

## 5. 诊断 + 完整改写

```text
先用无敌人话修改诊断，再给完整修改稿。

用途：
读者：
必须保留：
目标语气：

原文：
```

## 6. 商业方案 / 报价单

```text
用无敌人话修改重写成客户可理解、可验收的服务说明。优先写清范围、执行方式、交付物、指标和边界；删除“赋能、生态、闭环、全面提升”等无法验收的表述。所有数字和责任边界保持不变，只给正文：

【原文】
```

## 7. 技术排查

```text
用无敌人话修改这段技术回答。先给最高概率结论，再用日志或现象解释，给最短验证步骤和修复方法；不要平均罗列可能性，不讲无关基础知识。命令、版本和日志原样保留：

【原文】
```

## 8. 学术文本

```text
用无敌人话修改这段学术文字。保留术语和贡献边界，按“问题—现有缺口—关键机制—结果—限制”组织；删除自我评价和无依据的“首次、显著、全面、重要意义”。不得编造实验结果或引用：

【原文】
```

## 9. 简历

```text
用无敌人话修改这段项目经历。突出约束、本人贡献、关键机制、为什么必要以及结果；不要只写岗位职责，不为了贴 JD 删除技术深度。数字与所有权保持不变：

【原文】
```

## 10. 公众号 / 品牌文案

```text
用无敌人话修改这段品牌文字。保留品牌立场，但用具体场景、能力和证据支撑，不写时代浪潮、创新赋能、信任底座、开启新篇章一类通用口号。不要把所有句子都改成排比：

【原文】
```

## 11. 工作消息

```text
用无敌人话修改成一条可直接发送的工作消息。先写结论或请求，再写必要背景、动作和时间；礼貌但不铺垫，不改变责任和截止时间。只给消息正文：

【原文】
```

## 12. 保留个人锋芒

```text
用无敌人话修改，但不要把我的判断磨成“各有优劣”。保留我的立场、情绪强度和用词习惯，只修逻辑、重复和不自然句式：

【原文】
```

```text
3. 更有锋芒

```


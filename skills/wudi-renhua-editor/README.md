# 无敌人话修改 Skill

一个面向中文写作的深度改写 Skill。它处理的不是几个“AI 高频词”，而是整套生成式文本问题：

- 模板句过密
- 抽象词堆叠
- 虚构对立与假因果
- 结构过于规整
- 全文重复与概念漂移
- 证据、范围和语气失配
- 回答没有命中任务
- 体裁写错
- 作者判断和声音消失

核心原则：

> 人话不是口语化，而是事实不变、判断清楚、信息具体、结构服从任务、语气符合体裁。

## 文件结构

```text
wudi-renhua-editor/
├── SKILL.md
├── README.md
├── manifest.txt
├── references/
│   ├── diagnostic-taxonomy.md
│   └── rewrite-playbook.md
├── examples/
│   └── before-after.md
├── eval/
│   └── rubric.md
├── tests/
│   └── cases.md
└── templates/
    └── prompts.md
```

- `SKILL.md`：主规则，正常使用只需加载它。
- `diagnostic-taxonomy.md`：九类 AI 腔完整诊断体系。
- `rewrite-playbook.md`：通用改写算法与各体裁路由。
- `before-after.md`：20 组典型前后对比。
- `rubric.md`：100 分质量闸门与硬失败项。
- `cases.md`：18 个回归测试，防止 Skill 退化成禁词替换器。
- `prompts.md`：可直接复制的调用方式。

## 安装

将整个 `wudi-renhua-editor` 目录复制到你使用的 Agent / CLI 所支持的 Skill 目录中，并确保相对路径不变。平台若只识别 `SKILL.md`，主文件本身也包含完整的核心流程；其余文件用于长文、体裁化修改和质量复核。

## 最简单的调用

```text
用无敌人话修改处理下面这段。标准改写，保持事实和专业术语，只给正文：

【原文】
```

## 精确调用

```text
用无敌人话修改处理。

模式：轻改 / 标准改写 / 重构重写 / 诊断审校
用途：客户报价单
读者：第一次接触 GEO 的企业客户
希望保留：所有数字、平台、指标名称
绝对不能改：服务范围与责任边界
需要解释：否

原文：
……
```

## 推荐工作方式

- 短句或已经自然的文本：`轻改`
- 普通文章、报告、方案：`标准改写`
- AI 味很重、结构失效：`重构重写`
- 想先定位问题：`诊断审校`
- 商业、学术、技术、合同等文本：注明用途和不可变项

## 它不会做什么

- 不编造数据、案例、用户反馈或个人经历。
- 不把“人话”改成网络口语。
- 不机械禁止“不是……而是……”等正常句式。
- 不把专业术语全部改成“大白话”。
- 不为了短而删除必要边界。
- 不把所有作者都改成同一种温和、平衡的助手语气。
- 不以“规避检测”为目标；目标是让文本本身更准确、更有用。

## 设计特点

1. **先修高层问题**：事实、任务、逻辑、结构优先于词语。
2. **九类诊断**：能解释为什么像 AI，而不是只给禁词表。
3. **体裁路由**：报价单、论文、简历、技术排查、公众号和工作消息采用不同信息结构。
4. **语义守恒**：专门检查否定、责任、承诺、条件与术语。
5. **反过度修改**：已经自然时少改，正式文不强行口语化。
6. **质量闸门**：硬失败项、100 分量表和五项对抗测试。
7. **回归用例**：防止后续迭代走向“机械删词”和“表演式人类化”。
